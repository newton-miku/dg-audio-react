# 声狼 · DG-Audio-React

> 郊狼 3（DG-Lab 3.0）· 电脑声音反应控制 —— 让设备跟着声音的强弱与节拍走。

本程序**监听电脑正在播放的声音（系统输出）**，把音量/节奏实时映射为郊狼 3（DG-Lab 3.0）的刺激：电脑端开 WebSocket 服务，手机 DG-Lab App 扫码连上后即受控。

- 波形**持续输出**，且**强度与频率都随音量实时变化**，强弱的节奏由声音本身决定（不是固定间隔敲击）。
- 做**寸止 / 节拍器视频**：自动追踪视频节拍器的 **BPM**，锁定后每一拍点额外"加重一拍"，
  拍点之间的跟随不丢；说话声等不规整声音不会抢拍（可再靠门限压音量）。
- 也适合一般音乐/视频/游戏：随音量起伏、重音给脉冲。
- 通信：手机 DG-Lab App 通过局域网 WebSocket 扫码连接电脑，程序经 App 控制郊狼 3。
- 音频：默认抓「系统默认播放设备正在输出的声音」（WASAPI 环回，需要 `pyaudiowpatch`，支持 Python ≤ 3.12）。
  也可在界面里改选麦克风 / 立体声混音 / 虚拟声卡等输入设备。
- 控制：浏览器页面实时显示电平、输出幅度、锁定 BPM，可调模式/灵敏度/门限/质感/通道强度上限。
- 演示：`--demo` 用合成音源（带固定节拍）跑通全流程，无需郊狼也能看节拍锁定与界面。

## 环境准备（一次性）

依赖 Python **3.12**（WASAPI 环回库 `pyaudiowpatch` 只发布到 cp312 的预编译 wheel）。
本机已装 `uv`，用它建环境最简单：

```bash
uv venv --python 3.12 .venv
uv pip install --python .venv/Scripts/python.exe -r requirements.txt
```

> 没有 uv 的话也可以自己装一个 Python 3.12，然后 `python -m venv .venv` + pip 安装。

## 启动

```bash
# 只看音频设备
uv run --python .venv/Scripts/python.exe run.py --devices

# 正常启动
uv run --python .venv/Scripts/python.exe run.py
```

启动后会自动打开浏览器 `http://127.0.0.1:8900`。请**保持终端窗口开启**。

### 真机使用步骤

1. 郊狼 3 开机，手机 DG-Lab App 连接郊狼并**开启「被控」**。
2. 手机与电脑连**同一局域网**。程序页面左栏会显示二维码，用 App 扫码绑定（绑定后二维码消失、显示 target）。
3. **首次务必先把通道上限拉低（10~20）**，可在 App 内先自测小强度波形确认贴片位置。
4. 开始播放音乐/视频 → 点「开始（随声音输出）」。电脑声音越小越安静，刺激越小；声音大/鼓点越强刺激越强。
5. 观察「电平/输出」条，按感觉调：模式、灵敏度、门限、释放、质感，以及 A/B 通道各自上限。
6. 点「停止」会立即清空波形并把通道强度归零（紧急停止键）。

### 寸止 / 节拍器视频 用法

1. 模式保持默认 **节拍跟随**：输出会一直存在且**强度和频率都随声音实时变化**，
   检测到视频里节拍器的稳定节拍后，会额外在每一拍上加重一拍（状态栏显示锁定的 BPM）。
2. 人声/背景讲话不会"抢拍加重"（节奏不规整锁不上），但仍会随音量起伏；想让它安静只认节拍时，
   把「门限抬高」调大即可压掉低音量说话。
3. 单拍强弱随音量；先设低通道上限试拍，再慢慢加到合适。
> 说明：走 DG-Lab 需要 手机 App + 蓝牙转发，从音频到触感整体有约 0.2~0.4s 固有延迟。

## 声音源说明

- 「自动」＝ WASAPI 环回抓**默认播放设备**的全部输出（游戏+音乐+视频+通知音都会算进去）。
  不想被通知音触发就把「门限抬高」调大，或用下面方法只抓单个应用。
- 只抓某个应用：装 [VB-CABLE](https://vb-audio.com/Cable/) 或 Voicemeeter，
  把该应用改为输出到虚拟声卡的输入端，然后在页面「音频来源」里选对应的「[输入]」设备。
- 桌面通知较多时建议**关闭系统提示音**或在敏感时段调高门限。

## 参数说明

| 参数 | 含义 |
| --- | --- |
| 模式 | 节拍跟随(默认)：连续随声音、锁到节拍器时每拍加重 / 混合：+瞬态强调 / 平滑跟随：纯音量不追拍 |
| 质感 | 低沉撞击 / 标准 / 高频细麻 —— 波形频率档（低频更"沉"，高频更"麻/锐"） |
| 门限抬高 | 在自动底噪之上再加多少 dB 才算有声音（调大可抑制环境杂音/通知） |
| 灵敏度 | 音量→强度的曲线陡峭程度 |
| 释放 | 声音落下后刺激衰减的快慢（大=平滑粘连，小=干脆） |
| 通道上限 | 电脑下发的 A/B 主强度，同时受手机 App 侧上限约束 |
| 重新校准 | 静音 1 秒后点击，重新测定底噪 |

```bash
uv run --python .venv/Scripts/python.exe run.py --demo
```

合成音源会产生"底鼓+底噪"模式，可验证：电平表跳动、门限校准、调度不报错、WebUI 正常。

## 常见问题

- **控制页打不开**：确认终端没关、`web_port`（默认 8900）没被占用。可用浏览器直接开 `http://127.0.0.1:8900`。
- **App 扫不到码 / 连不上**：手机与电脑须同一网段；DG-Lab 端口（默认 56742）需在 Windows 防火墙放行。
  开着 **VPN/代理（Tailscale/加速器）** 时，程序自动选地址会优先挑真实局域网 IP（192.168 / 10 开头），
  不要用 100.x（虚拟网卡）。仍不行就在控制页「地址」里手动填电脑局域网 IP 再点「应用并刷新」，
  或直接在 `config.json` 里写死 `"dg_ip": "192.168.x.x"`。
- **没有"环回"设备、只有麦克风**：多半是 `pyaudiowpatch` 没装上（Python 3.14 会这样）。请用上面 3.12 环境。
- **抓不到某个软件的声音**：该软件可能用独占/特殊输出；用 VB-CABLE 把它的输出路由进虚拟声卡再选它。
- **强度不够/太冲**：先调通道上限；再试更高/更低的「质感」频率、改模式、调灵敏度与释放。
- **有声音却没反应**：看电平条是否在门限线之上；若一直低于门限点「重新校准」并把「门限抬高」调低。
- **延迟感明显**：波形本身 100ms 粒度 + 前视队列（约 0.18s）+ App 蓝牙转发，总延迟约 0.2~0.4s 属正常范围。

## 安全提醒

- 本程序直接控制电刺激设备。**请勿在无把握时调高上限**；心脏起搏器等体内电子设备使用者请勿使用。
- 开始前先低强度自测；过程中保持"停止"按钮随时可点。
- 开发者与程序对使用后果不承担责任。

## 目录结构

```
run.py              入口（--devices/--demo）
app/
  capture.py        音频捕获：pyaudiowpatch(环回) / sounddevice(输入) 双后端
  analyzer.py       dB 包络 / 门限 / 重音(onset) / BPM
  mapper.py         声音→幅度+频率（follow/beat/hybrid、质感档）
  scheduler.py      100ms 脉冲流调度、开关/清空、通道强度钳制
  dg.py             DG-Lab WebSocket 服务：扫码绑定 / 自动重绑 / 强度回传
  web.py + webui/   aiohttp 控制页 + WebSocket 遥测 + QR
  config.py / state.py / feed.py / demo.py
```
